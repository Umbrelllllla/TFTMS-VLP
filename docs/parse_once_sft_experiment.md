# 扁平条件 JSON 适配器试验

## 目标

训练一个只负责把自然语言描述转换为扁平条件 JSON 的 LoRA 适配器。候选车辆参数不进入模型；模型输出条件后，由固定程序完成候选判断。

## 训练数据

从原训练划分中筛出 7,231 条“文本解析结果与标注属性完全一致”的描述。本轮按条件组合分层抽取 512 条进行试验训练，训练一轮、batch size 1、LoRA rank 4、学习率 0.0001。

512 条中有 273 条使用泛称 vehicle 且不应产生具体类别，239 条明确包含 car、van、truck 或 bus。类别、颜色、距离、长度、宽度、高度、画面位置、朝向和遮挡均有覆盖，共包含 168 种字段组合。

训练图片与评测图片文件零重合，相机标识组零重合。模型训练输入只有原始描述，答案是对应的条件 JSON，不包含候选参数和最终 0/1。

## 评测结果

评测继续使用已经冻结的 120 条描述、240 个候选，与基础条件抽取、A 和 B 的验证集合完全相同。

| 指标 | 基础Qwen条件抽取 | 512条LoRA微调后 |
|---|---:|---:|
| 合法JSON | 106/120 | **120/120** |
| 条件完全正确 | 82/120 | **120/120** |
| 最终候选判断 | 201/240 | **240/240** |
| FP / FN | 4 / 21 | **0 / 0** |
| Precision / Recall / F1 | 0.9612 / 0.8250 / 0.8879 | **1.0000 / 1.0000 / 1.0000** |

同一验证集上的 A 为 231/240，B 为 234/240。本适配器在这套筛选开发子集上高于两者。

把标准条件送入同一程序时也是 240/240。磁盘保存的适配器已重新加载，锚点输出与训练结束时逐字符一致。

## 重复与模板检查

训练和验证中有 8/120 条描述文字完全相同；排除它们后，剩余 112 条描述对应的 224 个候选仍为 224/224。

把所有数字替换为占位符后，36 条验证描述与训练描述共享模板但数值不同，76 条没有匹配到训练模板：

| 描述分组 | 描述数 | 候选判断 |
|---|---:|---:|
| 文字完全相同 | 8 | 16/16 |
| 模板相同、数值不同 | 36 | 72/72 |
| 未匹配训练模板 | 76 | 152/152 |

模板检查只替换数字，不等价于完整的语言语义去重。当前验证集已经用于提示词选择和方案开发，因此 240/240 是开发验证结果，不是盲测或官方 test 分数。

## 第二套未参与方案开发的验证

适配器保存后没有继续训练，也没有修改提示词或比较程序。随后从剩余 579 张合格验证图片中固定抽取新的 120 张，排除训练文件、第一套扩大验证的 120 张图片和早期 A/B 验证的 12 张图片。

第二套数据同样包含 120 条描述、240 个候选，正负各 120。结果为：

| 指标 | 第二套新验证 |
|---|---:|
| 合法JSON | **120/120** |
| 条件完全正确 | **120/120** |
| 最终候选判断 | **240/240** |
| FP / FN | **0 / 0** |
| Precision / Recall / F1 | **1.0000 / 1.0000 / 1.0000** |

第二套数据与 512 条训练描述有 7 条文字完全相同；共有 43 条在只替换数字后匹配到训练模板。排除 7 条完全相同描述后，剩余 226 个候选仍全部正确。两套验证合计 240 条描述、480 个候选，均得到正确条件和正确候选判断。

第二套推理耗时 1,352.2 秒，平均 11.27 秒/描述。按这个更保守的速度外推 900 条 test 描述约需 2.82 小时，仍低于 A 本次 test 记录的 3.55 小时，但优势只有约 1.26 倍。

第二套仍是通过保守文本解析规则筛选的开发子集，只能说明模型在本任务当前支持的描述语法上表现稳定。它没有覆盖被筛除的复杂关系、歧义距离或未支持措辞。

## 时间与显存

训练 512 步耗时 2,120.2 秒，约 35.3 分钟；训练显存分配峰值约 3.82GB，适合当前 6GB 显卡。

微调后评测 120 条描述耗时 1,161.9 秒，平均 9.68 秒/描述。基础模型平均输出 30.21 token，微调模型为 29.71 token，因此变慢不是输出变长，而是当前 LoRA 推理路径的额外开销。

官方 test 有 900 条描述。按当前速度外推约需 2.42 小时；A 的 test 原始响应累计约 3.55 小时，预计仍可快约 1.47 倍。该数字只是速度外推。

## 结论

512 条描述已经证明专门训练条件抽取器可行，并消除了零样本阶段发现的泛称类别、字段错位和属性遗漏问题。第二套新图片验证也达到 240/240，因此下一步重点转为覆盖被筛除的复杂描述，并研究合并 LoRA 权重或更快推理后端。在官方 test 实际运行和提交格式复核前，不替换现有 A 提交包。

训练数据、适配器、逐步日志、原始输出与逐题评分保存在 `runs/qwen2b_parse_once_sft_v1`。该目录被 Git 忽略，只保存在本机。

第二套冻结数据、原始输出和评分保存在 `runs/qwen2b_parse_once_sft_holdout_v1`，同样只保存在本机。
