# 提示词对照实验

目标：检查直接匹配的错误是否能通过改变输入表达、明确规则、增加例题改善。保持 Qwen3.5-2B 官方权重、NF4 四位量化、非思考模式、逐题确定性生成不变。本轮不训练。

## 数据与步骤

固定随机种子 20261016，只从已划分的训练部分选取 60 张图片、120 个描述与候选配对，正负各 60。按属性、尺寸、距离、画面位置、朝向、遮挡划为六组，各 20 题；组名代表选题依据，不代表描述只包含该条件。实际这 120 题全是多条件描述，九类标注属性均有覆盖。

47 个负例只违反一个标注条件，其余 13 个违反多个条件。负例优先选择难例，因此结果不能代表原始数据自然分布。另选两张训练图片提供四条演示（两正两负），图片与诊断题严格不重叠，但不保证来自不同相机。

标注里的 public_properties 只用于选题与事后核对，不传给模型；正式题目的答案独立保存。V3 允许看到另外四条例题及其答案，这是少样例提示的组成部分。

| 版本 | 相对上一版的变化 |
|---|---|
| V0 | 原版提示词与 JSON |
| V1 | 全部字段变成逐行文字、展开嵌套、显式单位；字段名、数值不变 |
| V2 | 加入所有条件同时满足、忽略未提及属性、数字上下界与字段对应规则 |
| V3 | 再加入四条固定的正反例 |

V1 的格式转换已逐条反向还原核对，确保字段和值不丢失、不舍入。四版使用相同的 120 题、相同顺序。输入不截断，生成最多 8 个 token；输出除 0/1 外计作格式错误。

另有 10 道能力探针：4 道简单数字比较、2 道字段查找、2 道条件提取、2 道简化后的联合判断。条件提取要求 JSON，输出预算为 80 token，其他探针为 16；它们与四版二元匹配分开统计。每项样本很少，只提供诊断线索，不能证明某项能力完全掌握。

## 复现与查看

题目已固定，勿重复执行 prepare 覆盖它们。项目根目录运行：

```powershell
.\.venv-qwen2b\Scripts\python.exe -u scripts/qwen2b/diagnose.py run
.\.venv\Scripts\python.exe scripts/qwen2b/diagnose.py report
```

run 复用已完整写出的回答，可恢复中断任务；完整结果存在时会跳过已答题目。需独立重复实验时应建立新的输出版本，不覆盖本次文件。

结果目录为 `runs/qwen2b_prompt_diagnostic_v1`，被 Git 忽略，需另行保留：

- `manifest.json`：题目数量、覆盖范围、随机种子和文件指纹。
- `tasks.jsonl`：每次发给模型的完整消息及生成长度预算。
- `cases_answers.json`：诊断题和独立标注答案；不能整体输入模型。
- `demonstrations.json`：V3 的四条例题。
- `probe_answers.json`：简单能力探针的预期答案。
- `predictions.jsonl`：模型原始输出、耗时和显存。
- `README.md`、`metrics.json`：完成后生成的对照表。
- `review_cases.json`：事后将题目、答案和预测合并，便于逐题检查。

错误格式计为答错；计算 TP/FP/FN 时视为没有选中候选。每版同时报告正确数、漏选、错选、格式错误、F1，以及相对原版改对/改错的题目数。速度为顺序执行中的粗略测量，受预热、输入长度、显卡温度等影响。

选出有希望的版本后，还需在固定开发验证集上验证，不能把本轮训练侧的最好结果称为正式成绩。
