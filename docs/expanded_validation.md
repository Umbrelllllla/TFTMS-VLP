# 扩大验证：120张新图片、240对样本

目的：检查两种微调模型在更多新图片上的表现，并区分轻微尺寸越界与其他错误。只做推理，不重新训练、不修改原始标注、权重或提示词。

从原有800张开发验证图片中，排除上一轮12张，沿用文字与properties一致性筛选。剩余699张存在可用的正负候选，从中固定随机抽取120张，每张选一条描述、一个正例和一个较难的负例，总计240对，正负各120。九类属性均有覆盖。这仍是经过筛选的开发子集，不是全量验证或官方test。

新样本与训练样本的文件名相机分组标识无交叉；这一标识尚未外部核实为真实物理相机。10对新图片的描述文字与训练文字逐字重复，另外230对不重复，结果中分别报告。没有因为观察模型回答再替换样本。

主要指标仍按原始正负标签严格统计正确数、误选、漏选、F1和非法格式。B额外报告条件提取、满足性判断，以及仅读取完整JSON最终match字段的结果。

边界分析在推理前固定：所有不满足的条件都属于长/宽/高，且各项超出边界不超过0.05米，标记为“仅尺寸轻微越界”。本批有9对。报告实际差值，但不修改标签或主成绩；5厘米仅为诊断分组，不是官方容差，也不表示模型已判断正确。距离、位置、颜色等错误不归入这一组。

A、B分别加载上一轮保存的适配参数，保留相同的量化、数据类型、提示词和生成上限，先用一条旧样本检查加载后原始输出能否完全复现，再开始新验证。旧样本不计入240对。两组串行运行以控制显存。每条回答即时保存，全部结束后自动评分并更新docs/status.md。原始适配参数在推理前后校验指纹。

结果目录：`runs/qwen2b_supervision_ab_expanded_v1`。

- `manifest.json`：固定样本、权重指纹和分析规则。
- `pipeline_status.json`：当前阶段或失败原因。
- `A/`、`B/`：输入、原始回答、加载复现检查、完成状态和错误案例。
- `results.json`、`README.md`：两组均完成后生成的对照结果。

运行入口（本轮已经启动，不要重复启动）：

```powershell
.\.venv-qwen2b\Scripts\python.exe scripts/qwen2b/expand_ab.py pipeline
```

按上一轮速度，A约数分钟，B约数小时，实际受电脑负载影响。日志中出现持续增长的`A/B n /240`表示正在推进。失败时保存错误并停止后续阶段，不会把部分结果当成完整成绩。
