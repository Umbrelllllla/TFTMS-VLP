# 0/1 与逐属性标注：第一次小规模微调对照

本实验用 Qwen3.5-2B 的两个独立副本比较训练答案的差别。原始权重与既有实验保持不变，只保存新增的 LoRA 参数。LoRA 是给模型添加少量可训练参数，训练时原有参数不更新。

## 每组学什么

两组输入完全相同：一段英文描述，以及一个候选物体的结构化参数。训练答案不会放进验证输入。

- A：答案是 `0` 或 `1`。
- B：答案是 JSON，逐项列出类别、颜色、距离、长、宽、高、画面位置、朝向、遮挡是否被描述提及，具体条件是什么，以及候选物体是否满足；最后输出是否整体匹配。

例如描述说“黑色车辆，长度4.0至4.4米”，B需要学会颜色相关、条件为黑色；长度相关、条件为4.0至4.4米；没有提及的属性不参与判断。它再根据候选参数分别回答是否满足，最后汇总。

训练时，模型每生成一个答案词元，都与标准答案计算误差。词元是模型处理文字的小单位。B的中间字段也会产生训练误差，因此不只有最终0/1提供学习信号。不过当前实现仍是一个模型生成整份JSON，没有新增九个独立分类器，也没有保证它内部按JSON的先后顺序推理。字段结果是可以检查的模型输出，不是内部思考过程的证明。

## 固定数据与比较条件

训练128对、64张图片，验证24对、12张图片，正负样本各半。保留原来的训练/开发验证相机隔离划分，不使用test；训练图片排除之前提示词诊断与演示的图片。验证集12条不同描述，与本轮训练描述没有逐字重复。

标注从已有properties生成，但先用保守的文字解析检查条件与properties一致，再检查所有候选的条件判断是否符合原有正负标签。无法可靠解析、数值不一致或存在歧义的条目不用于本轮。它是自动筛选，不是全部经人工确认的标准答案。生成规则仅用于数据准备和独立核验，模型验证时仍需自己生成答案。

负例优先选择只违反少量条件的候选，避免只学会排除明显不同的物体。候选仍来自标注正例列表的并集，不能代表完整场景中所有物体。

两组都从同一官方基础模型开始，种子20261017、LoRA rank=4、alpha=8、dropout=0、学习率0.0001、batch=1，各训练一轮128次更新，训练顺序相同。使用4位NF4基础权重；每组训练前后分别跑同一组验证，保存所有原始回答。A最多生成8个词元，B最多384个。

**相同样本数和更新次数不等于相同计算量。** B的标准答案较长，训练词元更多，也会花更多时间；本实验比较的是这两套训练方案，而非严格等算力下的优劣。两组损失的数值不能直接比较。B还有较多固定JSON格式和“未提及”字段，后续若效果受限，需要考虑字段权重或输出简化。

## 如何评分

最终结果统计正确数、误选（把负例选中）、漏选（没选中正例）、非法格式和F1。F1综合衡量选中的准确程度与找全正例的能力。非法格式在正确率中一律计错；检索统计中按未选择处理。B只接受符合约定结构的JSON，不自动补全或修复。

B还统计属性相关性、真实提及条件的提取正确数、真实提及条件的满足性判断正确数、整份输出完全正确数，以及最终答案是否与它自己的各项判断矛盾。数值按JSON数值比较，其他条件按标准字段值精确比较；同义但未标准化的表达可能计为字段错误，不能一概解释成语言理解失败。非法回答也进入这些指标的分母。

这是12张开发图片的小型可行性对照，不能代表完整800张开发验证，更不能作为比赛分数或新场景能力证明。某组多对一两题不构成可靠优势。

## 文件与运行入口

- 数据：`runs/qwen2b_supervision_ab_v1/train.json`、`validation.json`。
- 固定设置与数据指纹：同目录 `manifest.json`。
- 实验：`scripts/qwen2b/run_ab.py`；A/B分别保存模型适配参数、逐步日志、训练输入、验证原始回答和完成检查。
- 评分：`scripts/qwen2b/report_ab.py`。
- [实际结果与错误案例](../runs/qwen2b_supervision_ab_v1/README.md)，机器可读结果在同目录 `results.json`。

从项目根目录运行，按A完成再B的顺序执行（单卡不并发）：

```powershell
.\.venv-qwen2b\Scripts\python.exe scripts/qwen2b/run_ab.py A
.\.venv-qwen2b\Scripts\python.exe scripts/qwen2b/run_ab.py B
.\.venv\Scripts\python.exe scripts/qwen2b/report_ab.py
```

已有A/B目录时训练脚本会拒绝覆盖。成功标志为每组 `complete.json` 的 `status=PASS`，以及评分脚本生成 `results.json`。这些命令用于解释本轮流程，完成后无需再运行训练。
